## 🧠 O que é Python?

Python é uma linguagem de programação:

- De **alto nível**  
- **Interpretada**  
- **Multiplataforma**  
- De **propósito geral**  

Ela foi projetada para ser **simples, legível e produtiva**, o que a torna ideal tanto para iniciantes quanto para aplicações profissionais.

---

## 🏗️ Onde Python é utilizado?

Python é amplamente utilizado em diversas áreas:

- 🌐 Desenvolvimento Web  
- 🤖 Inteligência Artificial  
- 📊 Ciência de Dados  
- ⚙️ Automação de tarefas  
- 🔬 Computação científica  
- 🎓 Ensino de programação  

---

## 📜 História da Linguagem

- Criada por **Guido van Rossum**  
- Início: final dos anos 80  
- Primeira versão: **1991 (Python 0.9.0)**  
- Versão atual base: **Python 3 (lançada em 2008)**  

> 💡 Curiosidade: o nome "Python" vem do grupo de comédia *Monty Python*.
